# Baremetal Bootstrap Project

Проект автоматизации развертывания ОС Ubuntu Server на виртуальных машинах и реальном железе с помощью `autoinstall` (Subiquity / cloud-init) и последующей пост-настройкой среды.

## 📂 Структура проекта

* `UbuntuAutoinstall.iso` — **[Готовый образ]** Собранный демонстрационный образ с учебными SSH-ключевыми парами для быстрого тестирования.
* **01-configs/** — Исходные конфигурационные файлы ответов (представлены в двух вариантах):
  * `baremetal-test.yml` — Версия **без LUKS-оболочки**. Отлично подходит для быстрых тестов внутри виртуальных машин.
  * `baremetal-crypto.yml` — Версия **с логикой LUKS-шифрования**. Предназначена для развертывания на реальном "боевом" железе для защиты данных.
* **02-ubuntu/** — Оригинальные дистрибутивы Ubuntu (ISO-образы).
* **03-iso-composer/** — Инструменты для сборки кастомного ISO.
  * `my-ubuntu/` — Распакованный дистрибутив.
  * `nocloud/` — Папка с конфигурацией (`user-data` и `meta-data`).
  * `composing-script.sh` — Скрипт сборки файлов папки обратно в загрузочный ISO.
* **04-bootstrap/** — Bash-скрипты для автоматизации настройки чистой системы после первой загрузки (накатываются вручную).

## 🚀 Как этим пользоваться

### 💿 Шаг 2: Сборка кастомного ISO (03-iso-composer)

В этой папке происходит подготовка ISO-образа со встроенными файлами ответов. Поскольку исходные файлы Ubuntu весят много, они исключены из Git. Перед сборкой выполните подготовку:

1. **Подготовка окружения:**
   * Скачайте официальный ISO-образ Ubuntu Server в папку `02-ubuntu/`.
   * Распакуйте содержимое скачанного ISO-образа в папку `03-iso-composer/my-ubuntu/` (например, с помощью утилиты `7z x` или смонтировав образ).
   * Убедитесь, что в папке `03-iso-composer/nocloud/` лежат ваши файлы ответов `user-data` и `meta-data`.

2. **Сборка образа:**
   Запустите скрипт `composing-script.sh` из папки `03-iso-composer`. Он упакует подготовленные файлы обратно в загрузочный ISO-образ.
3. При загрузке в меню GRUB нажмите `e` и в конец строки `linux /casper/vmlinuz` добавьте:
   ```text
   autoinstall ds=nocloud\;s=/cdrom/nocloud/
   ```
4. Начнется автоматическая установка. По окончании сервер автоматически выключится (для конфигурации реального железа). Извлеките образ и включите машину.

### Вариант 2: Правильный запуск (Под свои нужды)
Если вы разворачиваете рабочую среду, использовать встроенные учебные ключи **небезопасно**. Выполните следующие шаги:

1. **Генерация ключей и настройка конфига:**
   * Сгенерируйте свою собственную пару SSH-ключей.
   * Откройте нужный файл в `01-configs/` (для виртуалки или боевого железа) и замените публичный ключ в секции `ssh.authorized-keys` на свой.
2. **Сборка личного ISO:**
   * Скопируйте ваш измененный конфиг в папку `03-iso-composer/nocloud/` под именем `user-data`.
   * Запустите `composing-script.sh`, чтобы собрать ваш персональный ISO-образ.
3. **Установка и Bootstrap:**
   * Установите систему с вашего нового ISO (не забыв указать строку `autoinstall...` в GRUB).
   * После первой загрузки зайдите на сервер и запустите скрипты пост-настройки из папки `04-bootstrap` (например, для развертывания SSH и Fail2Ban).
